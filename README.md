# TextDiffTool

一款支持音频联动、文本对比、时间码定位、同音过滤、差异统计与结果分享的校稿工具。

## 使用方法

本项目是纯前端单页应用，无需安装依赖或打包构建。

1. 下载仓库后直接打开 `index.html`。
2. 在左侧粘贴准确底稿，在右侧粘贴带时间码的识别稿。
3. 运行对比后查看逐行差异、统计信息，并可联动本地音频定位。

文本、音频和历史记录均在浏览器本地处理，不会上传到服务器。历史记录只在当前标签页会话中保存，关闭标签页后清除。

## 功能

- 逐行文本差异与上一处／下一处导航
- 时间码定位及本地音频联动
- 严格同音等价词库
- 漏字、多字、错字与语速统计
- 只读对比结果分享
- 深色模式和本地历史记录

## 发布

仓库中的 `index.html` 即正式入口，可直接通过任意静态网页服务发布，无需 Node.js 或构建工具。
