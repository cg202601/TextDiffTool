# TextDiffTool

支持音视频联动、时间码定位、同音过滤、差异统计和 HTML 报告导出的本地校稿工具。当前版本：**5.2 基础版**。

## 使用方法

本项目是纯前端单页应用，无需安装依赖或打包构建。

1. 下载 Release 附件，或直接打开仓库中的 `index.html` / `TextDiffTool_v5.2.html`。
2. 在左侧粘贴准确底稿，在右侧粘贴带时间码的识别稿。
3. 运行对比后查看逐行差异、统计信息，并可联动本地音频定位。

文本、音频和历史记录均在浏览器本地处理，不会上传到服务器。历史记录只在当前标签页会话中保存，关闭标签页后清除。

## 5.2 更新

- 逐行文本差异与上一处／下一处导航
- 时间码定位及本地音频联动
- 输入框和历史记录保留完整时间码，比对时仅使用字幕正文
- 导出 HTML 报告包含可选中复制的两份完整稿件和差异结果
- 复制当前播放或暂停位置的时间码（快捷键 C，按 25fps 换算）
- 口播密度默认按底稿计算
- 默认自定义忽略字：`啊,呀,呢,吧,嗯,哎,呃,哦`
- 严格同音等价词库
- 漏字、多字、错字与语速统计
- 只读对比结果分享
- 深色模式和本地历史记录

原 `v5.1.0` 标签和发布附件保持不变。

## 验证与发布

浏览器回归使用 Node.js 和 Playwright：`node tests/regression.cjs`。可通过 `PLAYWRIGHT_MODULE` 指定已有 Playwright 模块路径，通过 `PLAYWRIGHT_BROWSERS_PATH` 指定浏览器目录。

沿用 `v主版本.次版本.0` 标签和 GitHub Release 单文件 HTML 附件的发布方式。仓库中的 `index.html` 为该版本默认入口，无需构建。
