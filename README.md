# TextDiffTool

支持音视频联动、时间码定位、同音过滤、差异统计和 HTML 报告导出的本地校稿工具。当前最新版本：**5.5 校对工作台版**。

## 选择版本

| 版本 | 入口 | 适合的工作 |
| --- | --- | --- |
| 5.5 校对工作台版 | `index.html` / [TextDiffTool_v5.5.html](TextDiffTool_v5.5.html) | 比对、记录问题、跟进修改、保存进度 |
| 5.2 基础版 | [TextDiffTool_v5.2.html](TextDiffTool_v5.2.html) | 文稿比对、音视频联动、导出对比报告 |

两个版本均可从 [GitHub Releases](https://github.com/cg202601/TextDiffTool/releases) 下载独立 HTML 附件，直接在浏览器打开。

## 使用方法

本项目是纯前端单页应用，无需安装依赖或打包构建。

1. 下载对应版本的 Release 附件，或打开仓库中的版本入口。
2. 在左侧粘贴准确底稿，在右侧粘贴带时间码的识别稿。
3. 运行对比后查看逐行差异、统计信息，并可联动本地音频定位。

文本、音视频和校对记录均在浏览器本地处理，不会上传到服务器。基础版历史记录只保留在当前标签页会话中。5.5 会另外将项目进度保存在本机浏览器中，关闭后可恢复；可通过“另存项目”保存为文件，再用“打开项目”继续。

## 5.5 新增

- 问题备注记录准确的播放时间；按 M 暂停并添加备注。
- 待确认、需要修改、已确认无误、已修正四种状态，支持筛选。
- 工作台默认收起，展开后以限定高度的紧凑列表独立滚动，支持记住展开状态。
- 问题清单只导出需要修改项和带未完成备注的待确认项，分组并提供定位目录及文字差异着色。
- 每条备注支持一键复制时间码和说明；完整对比报告保留两份稿件及文字差异，不包含备注或处理进度。
- 悬浮条支持上一问题、下一问题、返回工作台；手动点击对比行时同步当前备注，同一行多条备注按播放位置切换。
- 自动保存稿件、设置、备注、状态、播放位置和校对位置；支持项目文件导入与导出。音视频不嵌入项目文件，重新选择同一文件后可恢复播放位置。

## 5.2 更新

- 逐行文本差异与上一处／下一处导航
- 时间码定位及本地音频联动
- 输入框和历史记录保留完整时间码，比对时仅使用字幕正文
- 导出 HTML 报告包含可选中复制的两份完整稿件和差异结果
- 复制当前播放或暂停位置的时间码（快捷键 C，按 25fps 换算）
- 口播密度默认按底稿计算
- 默认自定义忽略字：`啊,呀,呢,吧,嗯,哎,呃,哦`
- 严格同音等价词库
- 漏字、多字、错字与语速统计
- 只读对比结果分享
- 深色模式和本地历史记录

原 `v5.1.0` 标签和发布附件保持不变。

## 验证与发布

浏览器回归使用 Node.js 和 Playwright：`node tests/regression.cjs` 验证 5.2，`node tests/workflow55.cjs` 验证 5.5。可通过 `PLAYWRIGHT_MODULE` 指定已有 Playwright 模块路径，通过 `PLAYWRIGHT_BROWSERS_PATH` 指定浏览器目录。

沿用 `v主版本.次版本.0` 标签和 GitHub Release 单文件 HTML 附件的发布方式。仓库中的 `index.html` 为该版本默认入口，无需构建。
